# ⚡ FiveQThoughts

**Deine neuesten TheBrain Quick Thoughts auf einen Blick – für Mac und Windows.**
*Your latest TheBrain Quick Thoughts at a glance – for Mac and Windows.*

![FiveQThoughts](https://mbaas2.github.io/FiveQ/img/mac-de-light.png)

🌐 **Website, Screenshots & Anleitung / Website, screenshots & guide:** [mbaas2.github.io/FiveQ](https://mbaas2.github.io/FiveQ/)

## Deutsch

- Die 5 (bis 20) neuesten Quick Thoughts als Kacheln, automatisch aktuell (Live-Sync)
- Neue Gedanken mit Text, Links und Bildern aus der Zwischenablage anlegen (Taste `N`)
- Text oder Grafik mit einem Klick kopieren, bearbeiten, löschen
- Globaler Shortcut `⌃⌥Q` (Mac) / `Strg+Alt+Q` (Windows)
- Lokale TheBrain-API mit automatischem Cloud-Fallback
- Deutsch & Englisch, helles & dunkles Design

**Installation:** Windows-Installer bzw. Mac-Download unter [Releases](https://github.com/mbaas2/FiveQThoughts/releases/latest). Danach auf **⚙ API** klicken und den TheBrain-API-Key eintragen ([app.thebrain.com/api-keys](https://app.thebrain.com/api-keys) oder TheBrain → *Settings → User → Local API*).

## English

- The 5 (up to 20) newest Quick Thoughts as tiles, always up to date (Live Sync)
- Create thoughts with text, links and images from the clipboard (key `N`)
- One-click copy of text or images, edit, delete
- Global shortcut `⌃⌥Q` (Mac) / `Ctrl+Alt+Q` (Windows)
- Local TheBrain API with automatic cloud fallback
- English & German, light & dark theme

**Install:** Windows installer or Mac download on the [Releases](https://github.com/mbaas2/FiveQThoughts/releases/latest) page. Then click **⚙ API** and enter your TheBrain API key ([app.thebrain.com/api-keys](https://app.thebrain.com/api-keys) or TheBrain → *Settings → User → Local API*).
